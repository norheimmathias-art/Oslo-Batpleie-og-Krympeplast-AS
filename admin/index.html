Netlify-synkronisering

Hent forespørsler direkte fra Netlify Forms. Submissions vises også i Netlify-dashboardet under Forms-fanen.

Slik finner du token og Site ID:
1. Gå til Netlify → User Settings → Personal access tokens og opprett en ny token.
2. Site ID finner du under Site settings → General → Site information.
